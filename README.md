# moovicity-app
MOOVICITY - Plataforma de mobilidade inteligente para trabalhadores urbanos. Fornece previsões de atraso, rotas alternativas e certificação automática de atrasos. # 🏙️ MOOVICITY
> **A sua jornada sob controle, sua vida em movimento.**

O **MOOVICITY** é um Super App de mobilidade urbana focado na experiência do passageiro ferroviário na Europa (especialmente Portugal). Ele combina dados em tempo real, previsibilidade por IA e serviços essenciais para transformar o tempo de espera em conveniência.

## ✨ Funcionalidades Principais
* **Dashboard Urban Pulse:** Monitoramento em tempo real de atrasos e status de linhas.
* **Caminhos Alternativos:** Integração multimodal (Bus, Uber, Bolt) para imprevistos.
* **Certificado de Atraso:** Geração automática de justificativa formal com QR Code para o RH.
* **Hub de Conveniência:** Localização rápida de farmácias, hospitais, WCs e cafés próximos às estações.

## 🛠️ Stack Tecnológica (Sugerida)
* **Frontend:** React Native / Expo (iOS & Android)
* **Backend:** Node.js com TypeScript
* **Banco de Dados:** Supabase (PostgreSQL)
* **APIs:** IP Open Data (Comboios), OpenWeather, Google Places.
